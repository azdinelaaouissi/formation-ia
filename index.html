Comment utiliser cette formation

Suivez les modules dans l'ordre du parcours : chaque cours introduit les notions, chaque TD les met en pratique avec du code exécutable et commenté. Les cours complets de la section Ressources reprennent un thème entier en un seul document, utiles pour réviser.

  • Recherche : tapez / pour chercher un cours ou un mot-clé (ex. « transformer », « FAISS », « ReAct »).
  • Progression : cliquez sur le rond à droite d'une carte pour la marquer terminée. La progression est stockée localement dans votre navigateur, rien n'est envoyé.
  • Hors-ligne : chaque page est autonome ; clonez le dépôt et ouvrez index.html.
